HUMA 组装说明

HUMA 是基于 Freeduino 的 Arduino 兼容开发板。 设计上可像早期收音机套件一样，亲手焊接全部零件完成组装。 具备基础焊接经验即可完成。

开始组装 零件清单

若久未焊接，可先阅读 漫画学焊接（韩文）。

HUMA 为开源硬件。对组装或使用过程中造成的板卡损坏以及人身、财产损失不承担任何责任。

原理图、工艺图及相关文档采用 CC BY-SA 许可。

安全提示 请自行注意安全。组装时佩戴护目镜等防护用具，谨防烙铁烫伤，并在通风良好处操作。

工具与零件

对照 HUMA PCB 与零件清单，确认零件齐全。

焊接

原则：由矮到高、由板内到板外、由耐热到不耐热依次焊接。

先焊最矮的 3.3V SMD 电容。正极(+)一侧有色带标记。

使色带朝向 2.2u 丝印方向，先焊一侧定位，再完成另一侧。

说明 丝印为 2.2u，实际使用了 10uF 电容。

再在电容旁的焊桥上上锡，连接 USB 与 3V3，即可使用 FT232BL 提供的 3.3V。

说明 若 3.3V 需要更大电流，可在板背面安装 MIC5219 与 470pF，并将 LDO 与 3V3 焊桥连通，由 5V 转换供电。

接着焊接 USB 转串口芯片 FT232BL（或 FT232BM）。若不熟悉 SMD IC，请先参考 SMD 焊接指南（韩文）。

说明 用放大镜仔细检查引脚是否虚焊或短路。其余零件装完后再返修会非常困难。

板上共需 7 只 100nF。焊盘兼容 SMD 1608 与圆片陶瓷电容。若选用 SMD，现在焊接。100nF 无极性。

至此，本板上最难的 SMD 工序已完成。

按板上阻值安装电阻。使用 1/4W 或 1/8W、5% 普通电阻即可。1% 更贵但对数字电路帮助不大；1/2W 体积大更难装。

说明 标有 *470 的三只电阻为 LED 限流电阻，330Ω~1kΩ 均可（示例使用 680Ω）。

焊接电源座旁的二极管与 USB 下方的磁珠。也可像原版 Arduino 一样在 PTC0805 位置装自恢复保险丝。二者择一。

翻面焊接 7805。先点焊一只脚定位，

摆正后再焊其余焊盘。

焊接谐振器（蓝色）与晶振（银色）。

安装三只 3mm LED。注意极性：短脚（或削平面）朝向丝印文字（R/T、L、PWR）一侧。

安装 ATmega IC 座。图中使用可裁切插座，并用胶带与排母临时固定后再焊接。

说明 美纹纸胶带若尽快撕下通常不留残胶。剪几段约 3cm 的胶带，组装时临时固定零件很方便。

若尚未安装 SMD 100nF，现在焊接 7 只陶瓷 100nF。

安装 47uF~100uF 电解（或固态）电容。亦提供 SMD 焊盘。白色色带（负极）朝向丝印平坦一侧。

接着焊接 USB 座、电源座、复位键、ISP 排针等。

需要 6 针与 8 针排母各两根。若买的是长条，先拔出裁切处的针脚，

再在缺口处切断使用。

有扩展板时可先插上以保持垂直（否则用胶带固定）。先焊两端定位，取下扩展板后再焊其余针脚。

焊接全部完成。按缺口方向将 ATmega 插入 IC 座。

插上电源选择跳线（USB / 外部电源）即告完成。

烧录引导程序

若芯片未预烧 Arduino 引导程序，需用 AVR ISP 首次烧录一次。

预编译 hex 位于 Arduino IDE 安装目录：

  • ATMEGA8: hardware/arduino/bootloaders/atmega8
  • ATMEGA168, ATMEGA328: hardware/arduino/bootloaders/atmega
